# Global-Wellbeing-Analysis

## Project Overview
An interactive Power BI dashboard exploring global wellbeing patterns, differences across countries, and key indicators influencing wellbeing.

## Key Questions
- How does wellbeing vary across countries and regions?
- Which countries have the highest and lowest wellbeing scores?
- What relationships exist between wellbeing and socioeconomic indicators?
- How do wellbeing indicators compare across countries?

## Tools & Skills
- **Power BI** – Data visualisation and interactive reporting
- **Power Query** – Data cleaning and transformation
- **Data Modelling** – Relationships and data organisation
- **Drillthrough** – Country-level analysis

## Project Structure
- **Overview Dashboard:** Global wellbeing trends and comparisons.
- **Country Drillthrough:** Detailed analysis of individual countries.

## Data Source
[Global wellbeing dataset (2015).](https://www.kaggle.com/datasets/unsdsn/world-happiness)
